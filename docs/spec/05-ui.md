# 05 · UI & design system

**The look of uteach is fixed by a reference app.** Every screen must look like it belongs to that app.
Build screens only from `components/ui` (shadcn primitives, restyled) and `components/patterns` (described below).
Don't invent new colors, sizes, shadows or layouts. If a screen needs something new, add it as a pattern first,
show it on `/dev/ui`, then use it.

## 3. Typography

- **Font:** Plus Jakarta Sans (load with `next/font/google`, weights 400/500/600/700/800).
- ⚠️ **Plus Jakarta Sans has no basic Cyrillic** (its `cyrillic-ext` subset starts at U+0460, so Russian letters are missing).
  Use the stack `"Plus Jakarta Sans", Manrope, ui-sans-serif, system-ui, sans-serif` and load **Manrope** with the
  `cyrillic` subset, so Russian text gets a similar geometric font instead of a random system one. Check the `ru`
  pages visually. If Manrope looks wrong next to Jakarta, try Onest.
- Sizes (from the reference): page title `text-2xl sm:text-[28px] font-extrabold tracking-tight`; card title
  `text-xl font-bold`; dashboard heading `text-[22px] font-bold`; body and table text `text-[15px]`; small/meta
  `text-sm` / `text-xs`; stat value `text-2xl font-bold`.

## 4. Layout: `AppShell`

- **Sidebar** (desktop ≥ `lg`): width 248 px, `bg-card`, right border `border-border/70`. Logo block at the top
  (icon in a `size-9 rounded-xl bg-primary/10` square + "uteach" wordmark in `text-xl font-extrabold`, first part in primary).
  Rows: `rounded-xl px-3 py-2.5 text-[15px] font-medium`, Lucide icon `size-[18px] strokeWidth 1.8`.
  Active row: text and icon in primary. Groups expand with a chevron and a smooth grid-rows animation; children are
  indented with a left border; the **active child** has `bg-primary-soft font-semibold text-primary` and a 3 px primary
  bar on the left border.
- **Mobile** (< `lg`): the sidebar becomes a drawer from the left (shadcn `Sheet`), opened by a menu button in the
  top bar, with `shadow-shell` and a `bg-foreground/40` overlay.
- **Top bar:** `bg-card`, bottom border, `px-4 py-4 sm:px-6 lg:px-8`. Pill search on the left
  (`h-11 rounded-full bg-muted/80`, search icon in primary on the right). On the right: center switcher, language
  switcher, (M4+) notifications bell, user chip (initials avatar + name + role + chevron) that opens the user menu.
  No "messages" button.
- **Main:** `bg-background p-4 sm:p-6 lg:p-7 space-y-5`. Content sits in cards.

## 6. What NOT to copy from the reference

- The "Spik" name and logo, and school-only items (Library, Class, Subject, Transport, Hostel, Notice).
- Hard-coded text, demo people, `$` amounts and mock data. Text goes through next-intl; money through `formatMoney`.
- Hand-made overlays, dialogs and checkboxes. Use shadcn/Radix underneath and restyle them, so keyboard and screen readers work.
- TanStack Router code (`createFileRoute`, `Link` from TanStack). uteach uses Next.js App Router and the next-intl `Link`.
- Fixed `min-w-[960px]` tables. Use the mobile card layout instead.
- Raw color classes (`bg-blue-100`, hex values). Only tokens.

## 6b. Decisions made while planning M0.5

> PROPOSED (approved in the M0.5 plan, 2026-10-11):
> - Radius scale copied exactly from the reference: `sm = r − 4px`, `md = r − 2px`, `lg = r`, `xl = r + 4px`,
>   `2xl = r + 8px` (so `rounded-xl` is 18 px and `rounded-2xl` 22 px).
> - `--success` (hue 155) and `--warning` (hue 60) in the same soft style; chart tokens are `--chart-1..3`
>   (purple, sky, orange from the reference).
> - Wordmark "**u**teach" (first letter in primary) with a Lucide `GraduationCap` in the logo square until there is a logo.
> - The top-bar pill search is a "Go to…" page palette (Ctrl/⌘+K) until real search arrives (M1, students).
> - The center switcher is a pill dropdown in the top bar (with the trial/past-due chip); language is a round icon dropdown.
> - The sidebar is sticky (full height). `AppShell` is presentational so `/dev/ui` can render it with fake data.
> - Auth pages use `AuthLayout`: a centered `rounded-2xl` card on `bg-background` with the wordmark above.
> - Lists filter and paginate on the server via URL parameters (`q`, filters, `page`, `size` 10/25/50).
>   `DataTable` supports row selection, but screens use it only when they have bulk actions.
> - Success feedback is a toast; errors stay inline in the form.
> - `FormDialog` stays 460 px wide and scrolls its body for long forms.
> - Archive asks for confirmation in a dialog (see below for restore).
> - `/dev/ui` pattern-name headings and fixtures are not translated (developer page).
> - Manrope is the Cyrillic fallback; Onest is the backup if it looks off.

> PROPOSED (made while building M0.5, 2026-10-11):
> - Archive asks for confirmation; Restore (and re-enabling a staff member) runs at once and shows a toast,
>   because it is safe to undo.
> - Raw colors are blocked by a local ESLint rule, `uteach/no-raw-colors` (`apps/web/eslint-rules/`, unit tested).
>   It flags Tailwind palette classes (`bg-blue-500`, `text-white`), arbitrary colors (`bg-[#fff]`) and
>   hex/`rgb()`/`hsl()`/`oklch()` values in `apps/web/src`. Colors live only in `globals.css`. CI runs it with `pnpm lint`.
> - Below `sm`, `DataTable` rows become cards whose row actions sit in a bottom strip with 40 px tap targets.
> - Client patterns that take an icon from server pages (`FilterButton`) take a rendered element
>   (`icon={<CircleDot />}`), because component functions can't cross the server/client boundary.
> - Screenshots: `pnpm screenshots` resets the **local** DB, seeds a demo center, captures uteach at 1440 px and
>   390 px into `docs/design/screenshots/uteach/` and builds reference-vs-uteach images in
>   `docs/design/screenshots/compare/`. It is not part of `pnpm e2e`.
