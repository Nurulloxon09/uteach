## 3. Typography

- **Font:** Plus Jakarta Sans (self-hosted with `next/font/local`, weights 400/500/600/700/800).
- ⚠️ **Plus Jakarta Sans has no basic Cyrillic** (its `cyrillic-ext` subset starts at U+0460, so Russian letters are missing).
  Use the stack `"Plus Jakarta Sans", Manrope, ui-sans-serif, system-ui, sans-serif` and load **Manrope** with the
  `cyrillic` subset, so Russian text gets a similar geometric font instead of a random system one. Check the `ru`
  pages visually. If Manrope looks wrong next to Jakarta, try Onest.

> PROPOSED (CI fix, 2026-10-13): both fonts are **self-hosted** instead of fetched by `next/font/google` at build
> time (that fetch failed CI builds at random on #22 and #23). One variable woff2 per family lives in
> `apps/web/src/app/fonts/` with its OFL 1.1 license and a README: Jakarta = latin + latin-ext (subset from the
> `google/fonts` source), Manrope = the Google `cyrillic` file. Same CSS variables (`--font-jakarta`,
> `--font-manrope`), weights and `unicode-range` as before, and `fonts/fallback.css` keeps the exact Arial fallback
> metrics `next/font/google` generated, so the rendering does not change. Found while checking: the Jakarta fallback
> face covers all of Unicode and sits before Manrope, so Russian text is drawn in adjusted Arial and Manrope never
> loads (already true before this change; see Known gaps in `progress.md`).
- Sizes (from the reference): page title `text-2xl sm:text-[28px] font-extrabold tracking-tight`; card title
  `text-xl font-bold`; dashboard heading `text-[22px] font-bold`; body and table text `text-[15px]`; small/meta
  `text-sm` / `text-xs`; stat value `text-2xl font-bold`.

## 6. What NOT to copy from the reference

- The "Spik" name and logo, and school-only items (Library, Class, Subject, Transport, Hostel, Notice).
- Hard-coded text, demo people, `$` amounts and mock data. Text goes through next-intl; money through `formatMoney`.
- Hand-made overlays, dialogs and checkboxes. Use shadcn/Radix underneath and restyle them, so keyboard and screen readers work.
- TanStack Router code (`createFileRoute`, `Link` from TanStack). uteach uses Next.js App Router and the next-intl `Link`.
- Fixed `min-w-[960px]` tables. Use the mobile card layout instead.
- Raw color classes (`bg-blue-100`, hex values). Only tokens.
