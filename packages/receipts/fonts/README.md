# Receipt fonts

Bundled so receipt PDFs render the same everywhere (web app now, Telegram worker in M4), without network access.

| File                                    | Family                            | Source                                                             |
| --------------------------------------- | --------------------------------- | ------------------------------------------------------------------ |
| `PlusJakartaSans_*.ttf` (400, 700, 800) | Plus Jakarta Sans, the app's font | Google Fonts, Copyright 2020 The Plus Jakarta Sans Project Authors |
| `Manrope_*.ttf` (400, 700, 800)         | Manrope, fallback for Cyrillic    | Google Fonts, Copyright 2018 The Manrope Project Authors           |

Both are licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org). They were taken
from the `@expo-google-fonts/plus-jakarta-sans` and `@expo-google-fonts/manrope` packages, version 0.4.2.
